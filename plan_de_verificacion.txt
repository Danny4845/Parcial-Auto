Este documento contiene el protocolo de pruebas paso a paso para evaluar el
sistema SCADA, la seguridad criptográfica (PBKDF2/HMAC), la jerarquía de roles (RBAC)
y las 3 listas de visualización de usuarios.

-------------------------------------------------------------------------------
1. PRUEBA DE BOOTSTRAPPING (CONFIGURACIÓN INICIAL DEL GERENTE)
-------------------------------------------------------------------------------
[ ] 1.1 Limpiar los datos almacenados previamente en el navegador
        (Herramientas de Desarrollador -> Aplicación -> Almacenamiento Local -> Limpiar).
[ ] 1.2 Recargar index.html. Verificar que aparece la pantalla de Configuración Inicial:
        "Configuración Inicial Requerida: No existe ningún usuario Gerente..."
[ ] 1.3 Completar el formulario inicial creando el usuario Gerente (ej: "gerente1", clave "ger2026").
[ ] 1.4 Hacer clic en "Registrar Gerente Inicial". Verificar el mensaje de confirmación.

-------------------------------------------------------------------------------
2. AUTENTICACIÓN Y DISEÑO DE INTERFAZ
-------------------------------------------------------------------------------
[ ] 2.1 Una vez registrado el Gerente inicial, verificar que la pantalla cambia
        ÚNICAMENTE al formulario de "Iniciar Sesión".
[ ] 2.2 Comprobar la apariencia visual:
        - Fondo gris industrial oscuro, limpio y claramente visible.
        - Ausencia total de emojis y texto de ejemplo en las cajas de entrada.
[ ] 2.3 Ingresar con las credenciales del Gerente ("gerente1" / "ger2026") y presionar "Iniciar Sesión".
[ ] 2.4 Confirmar el ingreso exitoso al Dashboard SCADA.

-------------------------------------------------------------------------------
3. PRUEBA DE JERARQUÍA DE CREACIÓN Y VISUALIZACIÓN DE USUARIOS (3 LISTAS)
-------------------------------------------------------------------------------
[ ] 3.1 SESIÓN DE GERENTE:
    [ ] En el header, hacer clic en "Gestionar Usuarios".
    [ ] Verificar que en el formulario de creación los ÚNICOS roles a elegir son:
        - Supervisor / Ingeniero (Nivel Supervisión)
        - Operador (Nivel Operación)
    [ ] Verificar que el Gerente puede visualizar las 3 LISTAS SEPARADAS:
        1. Lista de Gerentes Registrados (con botón "Eliminar").
        2. Lista de Supervisores Registrados (con botón "Eliminar").
        3. Lista de Operadores Registrados (con botón "Eliminar").
    [ ] Crear un usuario Supervisor (ej: "super1", clave "super2026").
    [ ] Crear un usuario Operador (ej: "oper1", clave "oper2026").
    [ ] Cerrar sesión.

[ ] 3.2 SESIÓN DE SUPERVISOR / INGENIERO:
    [ ] Iniciar sesión como "super1" / "super2026".
    [ ] Hacer clic en "Gestionar Usuarios".
    [ ] Verificar que en el formulario el ÚNICO rol disponible es:
        - Operador (Nivel Operación)
    [ ] Verificar que el Supervisor ve ÚNICAMENTE 1 LISTA:
        1. Lista de Operadores Registrados (con botón "Eliminar").
        (Las listas de Gerentes y Supervisores permanecen ocultas).
    [ ] Cerrar sesión.

[ ] 3.3 SESIÓN DE OPERADOR:
    [ ] Iniciar sesión como "oper1" / "oper2026".
    [ ] Verificar que el botón "Gestionar Usuarios" NO APARECE en la barra superior.
    [ ] Confirmar que el usuario Operador no tiene permisos para crear ni ver usuarios.

-------------------------------------------------------------------------------
4. PRUEBA DEL PROCESO SCADA Y SEMÁFOROS
-------------------------------------------------------------------------------
[ ] 4.1 En sesión de Operador o Supervisor, hacer clic en "INICIO".
[ ] 4.2 Verificar que el estado del sistema cambia a "ACTIVO" y que los semáforos
        muestran sus colores semánticos reales (Rojo, Verde, Azul y Amarillo).
[ ] 4.3 Presionar "Entrada (E1)". Observar la animación del vehículo ingresando, la apertura
        del portón durante la ventana PA y la actualización del contador de plazas libres.
[ ] 4.4 Presionar "Salida (S1)". Verificar la prioridad de salida y apertura del portón.
[ ] 4.5 Presionar "RESET (CI)". Confirmar que el sistema vuelve a Condiciones Iniciales.

-------------------------------------------------------------------------------
Firma de Verificación:
[ ] Todos los pasos comprobados exitosamente.
