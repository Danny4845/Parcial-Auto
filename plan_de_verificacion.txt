Este documento contiene la lista de comprobación paso a paso para evaluar el
cumplimiento de los requisitos del proyecto SCADA, la ciberseguridad PBKDF2/HMAC
y la jerarquía de roles (RBAC).

-------------------------------------------------------------------------------
1. BOOTSTRAPPING (CONFIGURACIÓN INICIAL DEL GERENTE)
-------------------------------------------------------------------------------
[ ] 1.1 Limpiar datos almacenados previamente en el navegador (DevTools -> Application -> LocalStorage -> Clear All).
[ ] 1.2 Recargar index.html. Verificar que aparece el aviso:
        "⚠️ Configuración Inicial Requerida: No existe ningún usuario Gerente..."
[ ] 1.3 Completar el registro del Gerente inicial (ej: usuario "gerente1", clave "ger2026").
[ ] 1.4 Hacer clic en "Registrar Gerente Inicial". Verificar mensaje verde de confirmación PBKDF2.

-------------------------------------------------------------------------------
2. AUTENTICACIÓN PÚBLICA & BLOQUEO DE REGISTRO ABIERTO
-------------------------------------------------------------------------------
[ ] 2.1 Una vez creado el Gerente inicial, verificar que el sistema cambia ÚNICAMENTE a la pantalla de "Iniciar Sesión".
[ ] 2.2 Confirmar que NO existen pestañas ni formularios de registro público abiertos en la pantalla de Login.
[ ] 2.3 Ingresar con el usuario Gerente ("gerente1" / "ger2026") y presionar "🔑 Iniciar Sesión".
[ ] 2.4 Verificar que el Dashboard SCADA se abre exitosamente.

-------------------------------------------------------------------------------
3. PRUEBA DE JERARQUÍA DE CREACIÓN DE USUARIOS POR ROL (RBAC)
-------------------------------------------------------------------------------
[ ] 3.1 SESIÓN DE GERENTE:
    [ ] Hacer clic en el botón "➕ Crear Usuario" del header.
    [ ] Verificar que los ÚNICOS roles disponibles para seleccionar son:
        - Supervisor / Ingeniero (Nivel Planta)
        - Operador (Nivel Control)
    [ ] Crear un usuario con rol Supervisor (ej: usuario "super1", clave "super2026").
    [ ] Crear un usuario con rol Operador (ej: usuario "oper1", clave "oper2026").
    [ ] Cerrar sesión.

[ ] 3.2 SESIÓN DE SUPERVISOR / INGENIERO:
    [ ] Iniciar sesión como "super1" / "super2026".
    [ ] Hacer clic en el botón "➕ Crear Usuario".
    [ ] Verificar que el ÚNICO rol disponible para seleccionar es:
        - Operador (Nivel Control)
    [ ] Confirmar que NO puede seleccionar ni crear rol Gerente ni Supervisor.
    [ ] Cerrar sesión.

[ ] 3.3 SESIÓN DE OPERADOR:
    [ ] Iniciar sesión como "oper1" / "oper2026".
    [ ] Verificar que el botón "➕ Crear Usuario" NO APARECE en el header.
    [ ] Confirmar que el usuario Operador NO tiene acceso a crear ningún usuario.

-------------------------------------------------------------------------------
4. PRUEBA DEL PROCESO SCADA Y SIMULACIÓN
-------------------------------------------------------------------------------
[ ] 4.1 En sesión de Operador o Supervisor, presionar "▶ INICIO".
[ ] 4.2 Verificar que el estado del sistema pasa a "ACTIVO" y se inicia el ciclo del semáforo peatonal (SP).
[ ] 4.3 Presionar "🚗 Entrada (E1)". Observar la animación del vehículo ingresando, apertura del portón en la ventana PA y actualización del contador de plazas libres (99 Libres).
[ ] 4.4 Presionar "🚗 Salida (S1)". Verificar la prioridad de salida, apertura de portón y decremento en ocupación.
[ ] 4.5 Presionar "↺ RESET (CI)". Verificar que el sistema vuelve a condiciones iniciales.

-------------------------------------------------------------------------------
Firma de Verificación:
[ ] Todos los pasos comprobados exitosamente.
