PROMPTS UTILIZADOS PARA EL DESARROLLO DEL PROYECTO SCADA
Proyecto: Estacionamiento Automatizado (III Parcial)
Autores: Daniel Colmenares y Hernaldo Pérez Roa

-------------------------------------------------------------------------------
PROMPT 1: ESTRUCTURA Y BASE DE LA PÁGINA
-------------------------------------------------------------------------------
"Crea una aplicación web SCADA en una sola página (HTML, CSS y JS) para controlar 
un estacionamiento automatizado de 100 plazas. Debe tener una pantalla de inicio 
de sesión y un dashboard principal con un dibujo interactivo en Canvas."

-------------------------------------------------------------------------------
PROMPT 2: SEGURIDAD Y PROTECCIÓN DE COMANDOS
-------------------------------------------------------------------------------
"Agrega seguridad al inicio de sesión guardando las contraseñas con el hash PBKDF2 
y asegura que los botones de control del SCADA (Inicio, Reset, Simulación) estén 
firmados con HMAC para que nadie pueda manipularlos desde la consola de desarrollador."

-------------------------------------------------------------------------------
PROMPT 3: JERARQUÍA DE USUARIOS Y ROLES (RBAC)
-------------------------------------------------------------------------------
"Organiza el sistema con 3 roles: Gerente, Supervisor y Operador. 
- Si al abrir la app no hay ningún Gerente guardado, pide crear el Gerente inicial.
- El Gerente puede ver 3 listas de usuarios separadas (Gerentes, Supervisores, Operadores) 
  y puede crear nuevos usuarios.
- El Supervisor sólo puede crear y ver la lista de Operadores.
- El Operador sólo controla el sistema y no puede ni crear usuarios ni ver listas."

-------------------------------------------------------------------------------
PROMPT 4: DIBUJO EN CANVAS Y SIMULACIÓN
-------------------------------------------------------------------------------
"Dibuja en un Canvas 2D el mapa del estacionamiento con 100 puestos, un portón 
de barras animado con sensores FCA/FCC, carriles con carros en movimiento y 
3 semáforos (peatonal, entrada con indicador azul de plazas libres y salida)."

-------------------------------------------------------------------------------
PROMPT 5: DISEÑO VISUAL E INTERFAZ
-------------------------------------------------------------------------------
"Aplica un diseño visual elegante con fondo gris oscuro industrial y detalles 
en turquesa claro. Usa los colores reales de los semáforos (rojo, verde, azul y 
amarillo), quita todos los emojis y deja los campos de texto limpios."
