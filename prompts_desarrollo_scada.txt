Prompts de Desarrollo SCADA
Proyecto: Estacionamiento Automatizado (III Parcial)
Autores: Daniel Colmenares y Hernaldo Pérez Roa

Prompt 1: Estructura base del proyecto
"Necesito crear una aplicación web SCADA en una sola página utilizando HTML, CSS y JavaScript para controlar un estacionamiento automatizado de 100 plazas. Debe incluir un panel de inicio de sesión inicial y un dashboard principal que muestre el mapa interactivo del proceso mediante un Canvas 2D, integrando los controles operativos y métricas del sistema."

Prompt 2: Ciberseguridad y protección de comandos
"Implementa seguridad criptográfica nativa en JavaScript sin librerías externas. Las contraseñas deben guardarse aplicando el algoritmo hash PBKDF2 con salt aleatorio en localStorage. Además, los botones de control del SCADA (Inicio, Reset, Simulación) deben firmar cada comando con HMAC-SHA256 usando un nonce y timestamp para evitar que un usuario manipule el sistema desde la consola del navegador."

Prompt 3: Gestión de usuarios y jerarquía de roles
"Organiza el sistema mediante un control de acceso por roles (RBAC) con 3 niveles: Gerente, Supervisor y Operador. Si la aplicación inicia sin usuarios guardados, debe mostrar una pantalla inicial para registrar al Gerente de Planta. El Gerente puede ver 3 listas separadas (Gerentes, Supervisores y Operadores) y crear nuevos usuarios. El Supervisor sólo puede crear y visualizar a los Operadores. El usuario Operador sólo puede usar los mandos de control y no tiene acceso a crear ni ver listas de usuarios."

Prompt 4: Renderizado en Canvas 2D y simulación
"Dibuja en un Canvas 2D el mapa cenital del estacionamiento automatizado. Debe mostrar la distribución de las 100 plazas en bloques, el portón electromecánico animado con los sensores de fin de carrera FCA y FCC, los carriles de entrada E1/E2 y salida S1/S2 con vehículos en movimiento, y los semáforos del proceso (Peatonal, Entrada con indicador azul de plazas disponibles y Salida)."

Prompt 5: Estilo visual e interfaz de usuario
"Aplica un diseño de interfaz limpio y profesional utilizando una paleta de fondo gris oscuro industrial con detalles en turquesa claro. Conserva los colores reales de los semáforos (rojo, verde, azul y amarillo) para identificarlos claramente, remueve todos los emojis del sistema y mantén los cuadros de texto limpios sin ejemplos de relleno."
